# Fullscreen field

The field was always three columns, and the stage — where the consoles tile — got what the two rails
left. On a screen given over to watching agents, the operator wants the consoles to have all of it.

What this changes in settled spec: the field has a second layout, **fullscreen**, chosen in settings.
It hides every piece of furniture but the clock and the settings gear, which float as a tab-sized
chip over the top-right corner, and the windows tile the whole viewport. It applies only once the field is set up, and
`Ctrl`/`Cmd` + `K` and `P` stand down while it is on. The choice is kept in the browser, so the
browser now holds two things rather than only the console layout: like the layout, it describes this
screen, not the overseer. Updated `ui-ux.md` §1 (new §1.1), §5, §6 and §7.1, `data.md` §5, the
`architecture.md` §3 feature map and `tests.md`.
